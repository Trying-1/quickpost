## Post Maker Workflows

### Workflow 1: Create Basic Single Image Post

**Use Case:** Create a simple post with one image and text

**Steps:**
1. Open app (Post Maker tab is default)
2. Ensure "Single Image" template is selected
3. Tap "Add image" button in preview area
4. Select image from gallery
5. Wait for image to load
6. Tap text field and enter your text
7. (Optional) Adjust text styling
8. Tap "Save" button
9. Wait for "Success" dialog
10. Choose "Close" or "Open File"

**Result:** Image saved to `/Pictures/Instagram Post Maker/`

**Time:** ~30 seconds

---

### Workflow 2: Create Styled Single Image Post

**Use Case:** Create a post with custom text styling

**Steps:**
1. Follow Workflow 1, steps 1-6
2. Expand "Text Styling" section
3. Adjust text color (tap color box)
4. Change text box background color
5. Enable text shadow (toggle switch)
6. Adjust shadow color
7. Enable text glow (toggle switch)
8. Adjust glow color and radius
9. Change letter spacing (slider)
10. Adjust font size (slider)
11. Preview changes in real-time
12. Tap "Save" button

**Result:** Styled post saved to gallery

**Time:** ~2 minutes

---

### Workflow 3: Create Post with Image Adjustments

**Use Case:** Position and zoom image perfectly

**Steps:**
1. Follow Workflow 1, steps 1-6
2. Expand "Image Adjustments" section
3. Use zoom controls:
   - Tap "+" to zoom in
   - Tap "-" to zoom out
   - Hold for continuous zoom
4. Use position controls:
   - Tap arrows to move image
   - Hold for continuous movement
5. Tap "Reset" to restore defaults
6. Preview adjustments in real-time
7. Tap "Save" button

**Result:** Post with custom image positioning

**Time:** ~1 minute

---

### Workflow 4: Create Grid Post (2x2)

**Use Case:** Create a post with 4 images in a grid

**Steps:**
1. Open Post Maker tab
2. Tap "Grid Post" template
3. Tap "Import All (4)" button
4. Select 4 images from gallery
5. Wait for images to load
6. (Optional) Reorder images:
   - Long press and drag images in list
   - Preview updates automatically
7. (Optional) Remove/replace images:
   - Tap delete button on image
   - Tap image to replace
8. Enter text in text field
9. (Optional) Apply text styling
10. Tap "Save" button

**Result:** Grid post saved to gallery

**Time:** ~1 minute

---

### Workflow 5: Create Post Without Text

**Use Case:** Save image-only post

**Steps:**
1. Select template (Single or Grid)
2. Add image(s)
3. Leave text field empty
4. Tap "Save" button
5. Dialog shows "Saving without text..."
6. Success dialog appears

**Result:** Post with empty text box (no placeholder)

**Time:** ~20 seconds

---

### Workflow 6: Change Template Mid-Creation

**Use Case:** Switch between Single and Grid templates

**Steps:**
1. Start creating post (any template)
2. Add images and text
3. Scroll to top
4. Tap different template card
5. Preview updates immediately
6. Note: Images may be cleared when switching
7. Re-add images if needed
8. Continue editing
9. Save

**Result:** Post with new template

**Time:** Variable

## Image Cropper Workflows

### Workflow 7: Basic Bulk Image Cropping

**Use Case:** Crop multiple images with same aspect ratio

**Steps:**
1. Tap "Image Cropper" tab
2. Tap "Select Images" button
3. Select multiple images (e.g., 10 images)
4. Images load in list
5. First image displays in crop area
6. Adjust crop area:
   - Drag corners to resize
   - Drag edges to resize
   - Drag center to move
7. Tap "Next" button
8. Repeat for each image
9. Tap "Export All" button
10. Wait for processing
11. Success dialog shows count

**Result:** All images cropped and saved

**Time:** ~30 seconds per image

---

### Workflow 8: Advanced Cropping with Transformations

**Use Case:** Crop with rotation and flip

**Steps:**
1. Follow Workflow 7, steps 1-5
2. Adjust crop area
3. Tap rotate button (top right)
4. Image rotates 90° clockwise
5. Tap flip button
6. Image flips horizontally
7. Readjust crop if needed
8. Tap "Next"
9. Repeat for other images
10. Export all

**Result:** Cropped and transformed images

**Time:** ~45 seconds per image

---

### Workflow 9: Selective Cropping

**Use Case:** Crop only some images, skip others

**Steps:**
1. Import multiple images
2. Crop first few images
3. For images you want to skip:
   - Just tap "Next" without cropping
4. Continue through all images
5. Tap "Export All"
6. Uncropped images use default crop (60% centered)
7. All images export

**Result:** Mix of custom and default crops

**Time:** Variable

---

### Workflow 10: Review and Adjust Crops

**Use Case:** Go back and modify earlier crops

**Steps:**
1. Import and crop several images
2. Navigate forward through images
3. Tap "Previous" button to go back
4. Previous crop settings restore automatically
5. Adjust crop if needed
6. Navigate forward again
7. Settings preserved
8. Export when satisfied

**Result:** Refined crops

**Time:** Variable

---

### Workflow 11: Remove Unwanted Images

**Use Case:** Delete images from crop queue

**Steps:**
1. Import multiple images
2. Start cropping
3. Find image you want to remove
4. Tap delete button (next to counter)
5. Image removed from list
6. Next image loads automatically
7. Continue cropping
8. Export remaining images

**Result:** Only desired images exported

**Time:** ~5 seconds per removal

---

### Workflow 12: Add More Images During Cropping

**Use Case:** Import additional images mid-session

**Steps:**
1. Import initial batch of images
2. Crop some images
3. Tap FAB (floating action button)
4. Select more images
5. New images added to end of list
6. Continue cropping all images
7. Export all

**Result:** Combined batch exported

**Time:** Variable

## Tips & Tricks

### Post Maker Tips

**Tip 1: Quick Template Switch**
- Swipe horizontally on template selector
- Faster than scrolling

**Tip 2: Text Preview**
- Text updates in real-time
- No need to save to preview

**Tip 3: Empty Text Posts**
- Leave text blank for image-only posts
- No placeholder will appear in saved image

**Tip 4: Grid Image Order**
- Drag images in list to reorder
- Preview updates automatically
- No need to re-import

**Tip 5: Styling Presets**
- Remember your favorite settings
- Reapply manually for consistency

---

### Image Cropper Tips

**Tip 6: Crop Persistence**
- Crop settings saved automatically
- Navigate freely between images
- Settings restore when you return

**Tip 7: Default Crop**
- Skip cropping images you don't need to adjust
- They'll use 60% centered crop on export

**Tip 8: Batch Operations**
- Import all images at once
- Crop in one session
- Export all together

**Tip 9: Rotation Shortcuts**
- Tap rotate button multiple times
- Each tap rotates 90°
- 4 taps = full rotation

**Tip 10: Corner Handles**
- Drag corners for proportional resize
- Drag edges for one-dimension resize
- Larger touch targets for easier use

---

### Video Creator Tips

**Tip 11: Image Order Matters**
- Select images in desired sequence
- Reorder in list if needed
- First image = first frame

**Tip 12: Audio Timing**
- Match video duration to audio length
- Adjust image duration accordingly
- Preview before creating

**Tip 13: Processing Time**
- More images = longer processing
- Be patient during creation
- Don't close app during processing

---

### General Tips

**Tip 14: Permissions**
- Grant storage permissions when asked
- Required for saving files
- Can't save without permissions

**Tip 15: Gallery Visibility**
- Saved files appear immediately in gallery
- No need to restart gallery app
- Check "All" section in gallery

**Tip 16: File Locations**
- Posts: `/Pictures/Instagram Post Maker/`
- Cropped: `/Pictures/Image Cropper/`
- Videos: `/DCIM/` or `/Movies/`

**Tip 17: Quality Settings**
- Images saved at high quality (95% JPEG)
- Posts captured at 3x resolution
- No quality loss

**Tip 18: State Preservation**
- Switch tabs freely
- Your work is preserved
- Return to where you left off

## Common Issues & Solutions

### Issue 1: Images Not Appearing in Gallery
**Solution:** 
- Wait a few seconds
- Refresh gallery app
- Check file location in success dialog

### Issue 2: Save Button Disabled
**Solution:**
- Ensure image is loaded (preview shows image)
- Wait for "Save" button to activate
- Check if loading indicator is gone

### Issue 3: Placeholder Text in Saved Image
**Solution:**
- This is now fixed
- Empty text = empty text box
- No placeholder captured

### Issue 4: Crop Settings Lost
**Solution:**
- This is now fixed
- Settings persist automatically
- Navigate freely

### Issue 5: Can't Remove Grid Image
**Solution:**
- Tap delete button on image in list
- Or use "Clear All" to remove all

## Workflow Comparison

### Post Maker vs Image Cropper

**Use Post Maker When:**
- Creating social media posts
- Adding text to images
- Need templates
- Want styled output

**Use Image Cropper When:**
- Bulk cropping needed
- No text required
- Need transformations
- Processing many images

**Use Both When:**
- Crop images first
- Then create posts with cropped images
- Best quality control
